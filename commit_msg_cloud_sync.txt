feat: 实现简历数据云端持久化存储，解决 LocalStorage 空间限制并支持跨设备续作

1. 后端 (backend/index.js):
   - 新增 resume_data 数据库表，以验证码为 Key 存储 JSON 格式的简历内容。
   - 新增 /api/resume/save 接口：支持自动保存和更新。
   - 新增 /api/resume/load 接口：支持通过验证码拉取云端存档。

2. 前端 (App.tsx):
   - 引入自动同步机制：每当数据变更且 2 秒内无新输入时，自动将数据推送到服务器。
   - 跨会话支持：用户刷新或换设备后，输入验证码即可自动从云端拉取上次保存的内容。
   - UI 优化：在预览区状态栏显示“正在同步”及“上次同步时间”，让用户感到安心。

3. 用户体验改进 (ResumeForm.tsx):
   - 弱化“存储空间已满”的报错：当本地空间满时，UI 将转为显示“正在使用云端同步”，并使用金色的云朵图标替代红色警告。
   - 引导用户信任云端：明确告知用户即使本地满，数据也已在服务器安全存档。
